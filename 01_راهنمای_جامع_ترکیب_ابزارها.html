خلاصه اجرایی

این سند یک معماری مرجع سازمانی برای ساخت یک دستیار هوش مصنوعی است که کارهای اداری تکراری و پیچیدهٔ شما — از کار با سامانه‌های بیمه (tamin.ir)، مالیات (tax.gov.ir) و حقوق تا تولید اسناد پرداخت پیچیده در اکسل — را به‌طور کامل خودکار می‌کند. تفاوت این معماری با یک «چت‌بات» یا یک اسکریپت RPA در این است که سیستم یاد می‌گیرد: هر بار که کاری برایتان انجام می‌دهد، یک «مهارت» جدید به مخزن خود اضافه می‌کند و در دفعات بعد آن را بهبود می‌بخشد. پس از چند ماه استفاده، سیستم دیگر نیاز به دستور دقیق ندارد — اگر بگویید «فیش حقوق مرداد را مثل تیر با ۱۵٪ اضافه‌کار برای احمدی درست کن»، خودش می‌فهمد.

📌 نتیجه نهایی این معماری چیست؟ یک دستیار هوش مصنوعی که (۱) OpenHuman به‌عنوان مغز و حافظهٔ بلندمدت آن روی کامپیوتر شما اجرا می‌شود، (۲) Hermes Agent کنار آن به‌عنوان دستیار اجرایی خودآموز عمل می‌کند، (۳) mcp-server-excel به آن قدرت دستکاری کامل اکسل بدون نصب Microsoft Excel می‌دهد، و (۴) Browser Use امکان کار خودکار با سامانه‌های ایرانی فاقد API را فراهم می‌کند.

چرا این چهار ابزار؟

🧠 OpenHuman — مغز مرکزی

یک عامل هوش مصنوعی متن‌باز (GPL-3) نوشته‌شده به زبان Rust که روی سیستم شما اجرا می‌شود. تفاوت کلیدی: حافظه‌اش به‌صورت درخت مارک‌داون قابل‌خواندن در پوشه ~/.openhuman/wiki/ ذخیره می‌شود، نه یک vector database غیرقابل‌فهم. هر ۲۰ دقیقه به‌طور خودکار داده‌های شما را از منابع متصل (Gmail، Notion، Slack و...) واکشی و به‌روزرسانی می‌کند.

🤖 Hermes Agent — دستیار اجرایی

ساخت Nous Research — تنها عاملی که یک Learning Loop بستهٔ واقعی دارد. پس از هر کار پیچیده (بیش از ۵ فراخوان ابزار)، خودش یک «Skill» به‌صورت فایل Markdown با YAML frontmatter می‌سازد و در دفعات بعد آن را بهبود می‌دهد. از MCP به‌صورت first-class پشتیبانی می‌کند.

📊 mcp-server-excel — قدرت اکسل

یک سرور Model Context Protocol که به عامل هوش مصنوعی امکان می‌دهد بدون نصب Microsoft Excel فایل‌های .xlsx بسازد، بخواند، فرمول اضافه کند، PivotTable و نمودار بسازد، قالب‌بندی شرطی اعمال کند و... این ابزار برای «اسناد پرداخت پیچیده» شما دقیقاً ساخته شده است.

🌐 Browser Use — چشم و دست وب

یک کتابخانه Python متن‌باز با بیش از ۷۹ هزار ستاره در GitHub که به هر LLM اجازه می‌دهد یک مرورگر واقعی را کنترل کند: ورود به سامانه، پرکردن فرم، دانلود فایل، تعامل با CAPTCHA. برای سامانه‌های ایرانی مثل tax.gov.ir و tamin.ir که API عمومی ندارند، تنها راه عملی خودکارسازی است.

۱.۱ چرا یک «عامل» با یک «چت‌بات» فرق دارد

وقتی از ChatGPT می‌پرسید «فیش حقوق را چطور محاسبه کنم؟»، پاسخی متنی می‌گیرید. اما وقتی به یک Agent (عامل) می‌گویید «فیش‌های حقوق مرداد را برای ۵۰ کارمند بساز، در tamin.ir لیست بیمه را ثبت کن، و فایل نهایی را در OneDrive بگذار»، آن عامل باید بتواند: (۱) بفهمد کارمندان چه کسانی‌اند، (۲) اکسل باز کند و بنویسد، (۳) با مرورگر لاگین کند، (۴) داده‌ها را وارد کند، (۵) خطاها را مدیریت کند، (۶) نتیجه را گزارش دهد. این یعنی Perceive → Reason → Act در یک حلقهٔ بسته.

سه ویژگی که یک عامل واقعی را از چت‌بات جدا می‌کند

  1. Tool Use (استفاده از ابزار): عامل می‌تواند به فایل‌سیستم، اکسل، مرورگر، API و... دست بزند. در معماری ما این نقش را Hermes از طریق ابزارهای MCP بازی می‌کند.

۱.۳ پروتکل MCP: زبان مشترک ابزارها

Model Context Protocol (پروتکل زمینه مدل) که در نوامبر ۲۰۲۴ توسط Anthropic معرفی شد و در ۲۰۲۵-۲۰۲۶ به استاندارد صنعت تبدیل شد، همان چیزی است که «USB-C دنیای هوش مصنوعی» نامیده می‌شود. هر ابزاری که بخواهد به یک LLM متصل شود، به‌جای اینکه یک پلاگین اختصاصی برای ChatGPT، Claude، Hermes و... بنویسد، فقط یک MCP Server منتشر می‌کند و همه به آن متصل می‌شوند.

سه transport برای MCP

1. stdio

سرور به‌صورت یک فرآیند محلی روی سیستم شما اجرا می‌شود و از طریق stdin/stdout با کلاینت (Hermes) حرف می‌زند. سریع‌ترین و امن‌ترین گزینه. مناسب برای excel-mcp-server.

2. SSE (منسوخ)

Server-Sent Events روی HTTP. در نسخه‌های جدید MCP توصیه نمی‌شود.

3. Streamable HTTP

روش توصیه‌شده برای اتصالات از راه دور. اگر بخواهید excel-mcp-server را روی یک سرور مرکزی اجرا کنید و از چند کامپیوتر به آن وصل شوید، این گزینه است.

# فرمت استاندارد پیکربندی یک MCP Server در Hermes (~/.hermes/config.yaml)
mcp_servers:
  excel:
    command: "uvx"
    args: ["excel-mcp-server", "stdio"]
    tools:
      include: [create_workbook, write_data_to_excel, format_range,
                apply_formula, create_pivot_table, create_chart]
      prompts: false
      resources: false

۱.۴ Skill، Memory و Learning Loop

سه مفهوم بنیادی که کار کردن با این اکوسیستم را ممکن می‌کند:

Skill (مهارت)

یک «مهارت» در Hermes یک پوشه است که داخل آن یک فایل SKILL.md قرار دارد. این فایل دو بخش دارد: (۱) YAML Frontmatter که شامل name و description است و به عامل کمک می‌کند بفهمد چه زمانی این مهارت را فراخوانی کند، و (۲) بدنه Markdown که شامل دستورالعمل‌های گام‌به‌گام است.

---
name: monthly-payroll-generator
description: تولید فیش حقوق ماهانه با محاسبه بیمه، مالیات و اضافه‌کار
triggers:
  - "فیش حقوق"
  - "لیست حقوق"
  - "payroll"
---

# مهارت: تولید فیش حقوق ماهانه

## پیش‌نیازها
- فایل مرجع کارمندان در: `C:\HR\employees.xlsx`
- نرخ بیمه: ۷٪ سهم کارمند، ۲۳٪ سهم کارفرما
- نرخ مالیات پلکانی مطابق قانون ۱۴۰۴

## گام‌های اجرایی

1. با ابزار `read_data_from_excel` فایل کارمندان را بخوان
2. برای هر کارمند حقوق ناخالص = پایه + اضافه‌کار × ۱.۴ محاسبه کن
3. بیمه = min(حقوق_ناخالص، سقف) × ۰.۰۷
4. مالیات را از جدول پلکانی حساب کن
5. با `create_workbook` یک فایل جدید بساز
6. با `write_data_to_excel` داده‌ها را بنویس
7. با `format_range` رنگ‌بندی و مرزها را اعمال کن
8. با `apply_formula` جمع کل ستون‌ها را در ردیف آخر بگذار

Memory (حافظه)

در OpenHuman، حافظه یک درخت سه‌لایه است:

  • Source Tree: برای هر منبع داده (Gmail، Slack، Notion...) یک درخت جداگانه با ساختار L0→L1→L2 (خام، خلاصه، فوق‌خلاصه).
  • Topic Tree: برای هر «موضوع پرحرارت» (مثلاً «حقوق آبان» یا «بیمه احمدی») یک شاخه.
  • Global Tree: یک گره به‌ازای هر روز UTC که خلاصه‌ای از فعالیت آن روز است.

داده‌ها به قطعات ۳۰۰۰-توکنی تقسیم و به Markdown تبدیل می‌شوند، سپس در SQLite ذخیره و به‌صورت یک Obsidian Vault در مسیر ~/.openhuman/wiki/ mirror می‌شوند. این یعنی شما می‌توانید حافظه عامل را با یک ویرایشگر متن باز کنید و دستی اصلاح کنید.

Learning Loop (حلقه یادگیری)

در Hermes، این چهار مرحله است:

1

Task Execution

عامل کار شما را انجام می‌دهد و همه‌چیز را در سشن ثبت می‌کند.

2

Skill Extraction

اگر کار «پیچیده» بود (بیش از ۵ فراخوان ابزار)، Hermes خودش پیشنهاد می‌دهد یک Skill بسازد.

3

Skill Improvement

در دفعات بعد، اگر Skill شکست خورد یا شما بازخورد منفی دادید، Hermes با GEPA (Genetic-Pareto Prompt Evolution) آن را بهبود می‌دهد.

4

Skill Retirement

Skillهایی که مدت زیادی استفاده نشوند یا نتایج ضعیف بدهند، به‌طور خودکار بازنشسته می‌شوند تا context آلوده نشود.

# مهارت: سند پرداخت پیچیده

## پارامترها
- payer: شرکت پرداخت‌کننده (dict)
- payee: دریافت‌کننده (dict)
- items: لیست اقلام
- vat_rate: 0.10 (پیش‌فرض)
- municipal_tax_threshold: 100_000_000 ریال

## گام‌ها

### گام ۱: قالب اولیه
excel.create_workbook("D:\\Office\\Invoices\\INV-${date}.xlsx")

### گام ۲: هدر (سلول‌های ادغام‌شده)
excel.merge_cells(start="A1", end="H3")
excel.format_range(A1:H3, font_size=18, bold=true,
                   alignment="center", bg_color="#1e3a8a",
                   font_color="#FFFFFF")

### گام ۳: بلوک اطلاعات دو ستونی
- ستون A-D: اطلاعات پرداخت‌کننده
- ستون E-H: اطلاعات دریافت‌کننده

### گام ۴: جدول اقلام
excel.create_table(
    data_range="A10:F${n+10}",
    table_name="items",
    table_style="TableStyleMedium9"
)

### گام ۵: فرمول‌های محاسباتی

- جمع اقلام:
  =SUMPRODUCT(items[تعداد],items[قیمت واحد])

- تخفیف (اگر جمع > 500 میلیون):
  =IF(J1>500000000, J1*0.05, 0)

- مالیات بر ارزش افزوده:
  =(J1-J2)*0.10

- عوارض شهرداری (اگر > آستانه):
  =IF(J1>${municipal_tax_threshold}, J1*0.015, 0)

- جمع کل:
  =J1-J2+J3+J4

### گام ۶: تبدیل عدد به حروف فارسی
یک user function در excel نیست، پس از Python:
```python
from num2fawords import words
words(final_amount) + " ریال"
```
و در سلول قرار بده.

### گام ۷: قالب‌بندی حرفه‌ای
- border برای همه cells
- rtl direction
- fonts: B Nazanin برای متن، Tahoma برای اعداد
- footer با شماره صفحه و تاریخ

خطاهای پرتکرار

❌ "MCP server 'excel' failed to start" دلیل: uv در PATH نیست یا فایروال جلوی uvx را گرفته. راه‌حل: uv --version را تست کنید، سپس فایروال Windows Defender → Allow app → پایتون و uv را اضافه کنید.
❌ "Playwright: Executable doesn't exist" راه‌حل: uv run playwright install chromium را دوباره اجرا کنید. اگر تحریم مشکل ساخت، از یک mirror استفاده کنید: PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright.
❌ "متن فارسی در فایل اکسل ⊕⊕⊕ نمایش داده می‌شود" دلیل: encoding نادرست. راه‌حل: PYTHONIOENCODING=utf-8 را در env مربوط به mcp-excel در config.yaml بگذارید.

۹.۳ بهینه‌سازی هزینه API

  • Cache کردن: Hermes به‌طور خودکار سشن‌های تکراری را cache می‌کند. با hermes cache stats بررسی کنید.
  • مدل ارزان‌تر برای Retrieval: در OpenHuman → Memory settings، برای عملیات ingestion (خلاصه‌سازی هر chunk) از gemini-2.0-flash یا gpt-4o-mini استفاده کنید.
  • Local برای Vision: اگر GPU خوب دارید، ollama pull qwen2.5vl:7b برای CAPTCHA و OCR محلی.
