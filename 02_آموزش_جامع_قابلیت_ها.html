مقدمه: چگونه این سند را بخوانید

سند اول به شما نشان داد چگونه این چهار ابزار را نصب و به هم متصل کنید. این سند دوم به شما یاد می‌دهد چه کارهایی با آن‌ها می‌توانید انجام دهید. ما یک-به-یک تمام قابلیت‌های هر ابزار را با کد کامل، ورودی نمونه، خروجی نمونه و سناریوهای واقعی اداری ایرانی پوشش می‌دهیم.

💡 توصیه استفاده این سند به‌صورت مرجع طراحی شده است. لازم نیست سرتاسر بخوانید. وقتی می‌خواهید کار خاصی انجام دهید (مثلاً «چطور یک PivotTable با فیلتر بسازم؟»)، از فهرست به بخش مربوطه بروید، کد را کپی کنید، متغیرها را متناسب با کار خود تغییر دهید و اجرا کنید.
🎯 ساختار هر بخش هر قابلیت با این ساختار ارائه می‌شود:
  • 📋 Function Signature: امضای دقیق تابع
  • 📝 توضیح: این تابع چه کاری می‌کند
  • 🧪 مثال ساده: کوچک‌ترین مثال قابل اجرا
  • 🚀 مثال پیشرفته: استفاده در سناریوی واقعی

۱.۱ مدیریت Workbook

1️⃣ create_workbook

create_workbook(filepath: str) -> str

یک فایل اکسل جدید در مسیر مشخص می‌سازد. اگر فایل از قبل وجود داشته باشد، خطا برمی‌گرداند.

مثال ۱: ساخت فایل ساده

# در Hermes chat:
"یک فایل اکسل به نام 'فاکتور_۱۴۰۵_۰۴.xlsx' در D:\Office\Invoices بساز."

# Hermes به‌طور خودکار فراخوانی می‌کند:
create_workbook(filepath="D:/Office/Invoices/فاکتور_1405_04.xlsx")

# خروجی:
# "✅ Workbook created at D:/Office/Invoices/فاکتور_1405_04.xlsx"

مثال ۲: ساخت مسیر داینامیک بر اساس تاریخ

"هر روز یک فایل log جدید در D:\Office\Logs\ بساز با نام
log_YYYYMMDD.xlsx بر اساس تاریخ امروز میلادی."

# Hermes ابتدا تاریخ را می‌فهمد (2026-07-26)، سپس:
create_workbook(filepath="D:/Office/Logs/log_20260726.xlsx")

2️⃣ create_worksheet

create_worksheet(filepath: str, sheet_name: str) -> str

مثال: ساخت چند sheet در یک فایل

# ساخت فایل با چند sheet برای گزارش سه‌ماهه:
create_workbook("D:/Office/Q2_Report.xlsx")
create_worksheet("D:/Office/Q2_Report.xlsx", "فروردین")
create_worksheet("D:/Office/Q2_Report.xlsx", "اردیبهشت")
create_worksheet("D:/Office/Q2_Report.xlsx", "خرداد")
create_worksheet("D:/Office/Q2_Report.xlsx", "خلاصه")

# نکته: sheet پیش‌فرض 'Sheet' هم می‌ماند مگر اینکه delete_worksheet را صدا بزنیم

get_workbook_metadata(filepath: str, include_ranges: bool = False) -> str

۱.۲ خواندن و نوشتن داده

4️⃣ write_data_to_excel

write_data_to_excel(filepath: str, sheet_name: str, data: List[Dict], start_cell: str = "A1") -> str

لیست دیکشنری‌ها را در sheet می‌نویسد. کلیدهای دیکشنری اول به‌عنوان هدر ستون‌ها استفاده می‌شود.

مثال ۱: نوشتن جدول کارمندان

employees = [
    {"نام": "علی احمدی", "کد ملی": "0012345678",
     "پایه": 150000000, "سمت": "حسابدار"},
    {"نام": "سارا رضایی", "کد ملی": "0087654321",
     "پایه": 180000000, "سمت": "مدیر مالی"},
    {"نام": "محمد کریمی", "کد ملی": "0055443322",
     "پایه": 120000000, "سمت": "کارمند اداری"},
]

write_data_to_excel(
    filepath="D:/Office/Excel/employees.xlsx",
    sheet_name="لیست",
    data=employees,
    start_cell="A1"
)

# نتیجه:
# A1: نام | B1: کد ملی | C1: پایه | D1: سمت
# A2: علی احمدی | B2: 0012345678 | ...

مثال ۲: افزودن به داده موجود از سطر خاص

# اضافه کردن کارمند جدید در سطر ۱۵:
write_data_to_excel(
    filepath="D:/Office/Excel/employees.xlsx",
    sheet_name="لیست",
    data=[{"نام": "زهرا موسوی", "کد ملی": "0099887766",
           "پایه": 140000000, "سمت": "طراح"}],
    start_cell="A15"
)
⚠️ نکته دربارهٔ کد ملی اگر کد ملی با صفر شروع می‌شود، اکسل به‌طور خودکار صفر ابتدا را حذف می‌کند. راه‌حل: قبل از نوشتن، format_range را با number_format="@" اعمال کنید تا ستون به‌صورت متن ذخیره شود.

۱.۴ فرمول‌ها

🔟 apply_formula

apply_formula(filepath, sheet_name, cell, formula) -> str

مثال ۱: فرمول‌های اساسی

# جمع ساده
apply_formula("D:/Office/Excel/sales.xlsx", "Sheet1",
              "D10", "=SUM(D2:D9)")

# میانگین وزنی
apply_formula(..., "F1",
              "=SUMPRODUCT(B2:B100, C2:C100)/SUM(B2:B100)")

# پیدا کردن حداکثر با شرط
apply_formula(..., "G1",
              "=MAXIFS(D2:D100, C2:C100, \"فروش\")")

مثال ۲: فرمول مالیات پلکانی ایران ۱۴۰۵

# محاسبه مالیات حقوق پلکانی برای سلول E2 (ناخالص):
formula = """=IF(E2<=200000000,0,
           IF(E2<=400000000,(E2-200000000)*0.1,
           IF(E2<=600000000,20000000+(E2-400000000)*0.15,
           IF(E2<=800000000,50000000+(E2-600000000)*0.2,
           90000000+(E2-800000000)*0.25))))"""

apply_formula(
    filepath="D:/Office/Excel/payroll.xlsx",
    sheet_name="فیش‌ها",
    cell="F2",
    formula=formula
)

مثال ۳: VLOOKUP برای اطلاعات بیمه

# در sheet "بیمه" یک جدول با شماره بیمه و درصد داریم
# در sheet "فیش‌ها" برای هر کارمند درصد بیمه را استخراج می‌کنیم:

apply_formula(
    filepath="D:/Office/Excel/payroll.xlsx",
    sheet_name="فیش‌ها",
    cell="H2",
    formula='=VLOOKUP(B2, بیمه!A:C, 3, FALSE) * E2'
)

1️⃣1️⃣ validate_formula_syntax

قبل از اجرا، صحت syntactic فرمول را چک می‌کند بدون اینکه آن را واقعاً اعمال کند.

مثال: تست چند فرمول

for formula in candidate_formulas:
    result = validate_formula_syntax(
        filepath="D:/test.xlsx",
        sheet_name="Sheet1",

        print(f"❌ {formula} → {result['error']}")
    else:
        print(f"✅ {formula}")

۱.۶ جداول محوری (PivotTable)

create_pivot_table(filepath, sheet_name, data_range, target_cell, rows: List[str], values: List[str], columns: List[str] = None, agg_func: str = "mean") -> str

۱.۷ جداول رسمی Excel Table

1️⃣4️⃣ create_table

یک range را به Excel Table تبدیل می‌کند که فایده‌های زیادی دارد: مرتب‌سازی/فیلتر خودکار، فرمول‌های ساختاری، استایل پیش‌ساخته.

مثال: تبدیل range کارمندان به Table

create_table(
    filepath="D:/Office/Excel/hr.xlsx",

    data_range="A1:H51",
    table_name="tblEmployees",
    table_style="TableStyleMedium9"
)

# استایل‌های موجود:
# TableStyleLight1..21
# TableStyleMedium1..28
# TableStyleDark1..11

# فرمول‌های ساختاری قابل استفاده:
apply_formula(..., cell="K1",
    formula="=SUM(tblEmployees[پایه_حقوق])")

apply_formula(..., cell="K2",
    formula='=COUNTIF(tblEmployees[سمت], "مدیر")')

from browser_use import Controller, ActionResult
from playwright.async_api import Page

controller = Controller()

@controller.action("خواندن CAPTCHA متنی فارسی از تصویر با ID مشخص")
async def read_persian_captcha(image_id: str, page: Page) -> ActionResult:
    """CAPTCHA فارسی را با استفاده از OCR محلی می‌خواند."""
    element = await page.query_selector(f"#{image_id}")
    img_bytes = await element.screenshot()

    # فراخوانی مدل vision محلی
    import ollama
    response = ollama.chat(
        model='qwen2.5vl:7b',
        messages=[{
            'role': 'user',
            'content': 'این CAPTCHA فارسی را دقیقاً بخوان. فقط متن را برگردان.',
            'images': [img_bytes]
        }]
    )
    captcha_text = response['message']['content'].strip()

    return ActionResult(
        extracted_content=captcha_text,
        include_in_memory=True
    )

# استفاده:
agent = Agent(
    task="در tamin.ir لاگین کن. اگر CAPTCHA بود از read_persian_captcha استفاده کن",
    llm=llm,

)

مثال ۲: اکشن «کپی داده جدول به اکسل»

@controller.action("استخراج جدول HTML و ذخیره در فایل اکسل")
async def extract_table_to_excel(
    table_selector: str,
    output_path: str,
    page: Page
) -> ActionResult:
    """جدول HTML را می‌خواند و در xlsx ذخیره می‌کند."""
    rows = await page.query_selector_all(f"{table_selector} tr")
    data = []
    headers = []

    for i, row in enumerate(rows):
        cells = await row.query_selector_all("td, th")
        row_data = [await c.inner_text() for c in cells]
        if i == 0:
            headers = row_data
        else:
            data.append(dict(zip(headers, row_data)))

    # فراخوانی MCP Excel
    import subprocess, json
    subprocess.run([
        "uvx", "excel-mcp-server", "call", "write_data_to_excel",
        json.dumps({
            "filepath": output_path,
            "sheet_name": "Extracted",
            "data": data
        })
    ])

    return ActionResult(
        extracted_content=f"استخراج شد: {len(data)} سطر → {output_path}",
        include_in_memory=True
    )

۴.۲ tinyflows و tinyagents

OpenHuman یک engine گراف برای workflow های چند-مرحله‌ای دارد.

مثال: workflow ماهانه پرداخت حقوق

# ~/.openhuman/workflows/monthly-payroll.yaml
name: monthly-payroll
description: کل فرآیند حقوق ماهانه
trigger:
  cron: "0 9 1 * *"  # اول هر ماه، ۹ صبح

nodes:
  - id: fetch_overtime
    type: agent
    prompt: "از ایمیل‌های ماه گذشته، ساعات اضافه‌کار همه کارمندان را استخراج کن"

  - id: calc_payroll
    type: skill
    skill: generate-monthly-payroll
    inputs:
      overtime: "${fetch_overtime.output}"
    depends_on: [fetch_overtime]

  - id: approval
    type: human
    message: "فایل ${calc_payroll.output.filepath} آماده است. تأیید می‌کنید؟"
    depends_on: [calc_payroll]

  - id: submit_tamin
    type: skill
    skill: submit-tamin-list
    inputs:
      payroll_file: "${calc_payroll.output.filepath}"
    depends_on: [approval]

  - id: notify
    type: action
    action: send_email
    inputs:
      to: manager@company.ir
      subject: "حقوق ماه انجام شد"
      body: "شماره پیگیری تامین: ${submit_tamin.output.tracking}"
    depends_on: [submit_tamin]

import asyncio

async def process_invoice(pdf_path):
    agent = Agent(
        task=f"از {pdf_path} داده‌های فاکتور را استخراج کن",
        llm=llm
    )
    return await agent.run()

# اجرای ۵ به ۵ موازی
async def main():
    pdfs = get_pdf_list("D:/Office/Inbox/")
    semaphore = asyncio.Semaphore(5)

    async def bounded_process(pdf):
        async with semaphore:
            return await process_invoice(pdf)

    results = await asyncio.gather(
        *[bounded_process(p) for p in pdfs]
    )
